# Site map — every page, and where its button goes

The pages across the storefront and the one button each one ends in. **The rule:** every
page finishes with a single primary button → the booking form (03). No dead ends, no two
buttons competing for the click.

---

## The website (the main funnel)

| Page | What's on it | The button → |

## The blog (for search)

- The category-education posts (see [`../02-demand-generation/category-education.md`](../02-demand-generation/category-education.md)):
  "Is your smart TV watching you back?", "Why grandma's tablet is a target," and so on.
- Every post ends with the same single button → the booking form (03).
- Posts link to each other and into the main pages so search treats the site as an authority.

## Google Business listing

| Field | What goes in it |
| ----- | --------------- |
| Name / category | `CHANGE_ME` (e.g. "Computer support / home network service") |
| Service area | The ZIP codes of the active routes (see `../02-demand-generation/geo-targeting.md`) |
| Tagline | The winning slogan from `../00-brand-identity/slogans-and-jingles.md` |
| Website | The homepage |
| Reviews | The local-search flywheel — ask for one right after the first statement lands |

## The gallery (read-only, lives in localDNS)

- Address: `https://a777ance.github.io/localDNS/`
- It's published straight from `localDNS` and updates itself. This repo **links** to it —
  it's never copied or rebuilt here.
